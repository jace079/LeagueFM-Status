🚀 Snelle Start

1. Download het project

Download de ZIP via GitHub.

2. Maak een Discord Applicatie

Maak gratis een applicatie aan via de Discord Developer Portal.

3. Start setup.bat

De installer configureert alles automatisch.

4. Start League-FM RPC

Geniet van je nieuwe Discord status.

✅ Verificatie

Deze applicatie werkt uitsluitend voor DJ's van League-FM. Er wordt gecontroleerd of jouw naam voorkomt binnen de Discord-server en op de website.


Jace verwerkt geen persoonlijke gegevens van gebruikers.

📡 API

GET http://api.league-fm.nl/


De API levert realtime informatie over het huidige nummer, artiest en afspeelduur.
